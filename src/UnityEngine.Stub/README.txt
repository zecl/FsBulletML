UnityEngine.Stub
================
COMPILE-ONLY fake of UnityEngine so FsBulletML.Unity2D (netstandard2.1) and the
Unity F# sample scripts can compile on this Linux box, which has no Unity Editor.

This is NOT a substitute for the Editor. You cannot Play the Unity sample here.
When opening the sample in Unity 2022/6, do not use this assembly — reference
the real UnityEngine from the Editor instead.
